# AI调用策略：效果优先、候选范围固定

2026-10-15起，提高有效候选的研究与补证预算。放宽的是送审和研究限制，正式准入标准保持不变。

## 调用预算

所有任务继续使用gpt-5.6-sol。

| 任务 | 研究预算 | 触发和目的 |
| --- | --- | --- |
| 单节点图谱验证、事件桥接 | medium推理、medium搜索上下文、8,000输出Token、请求8次工具调用上限 | 本地固定候选>=4只，核实共同催化和逐股业务关系 |
| admission_analysis | medium推理、medium搜索上下文、6,500输出Token、请求5次工具调用上限 | 复用已有证据；证据过时、因果链或反证不足时允许补搜 |
| catalyst_refresh | 维持2,500输出Token、2次工具调用预算 | 既有观察/正式题材定时刷新；不用于创造初始股票池 |

输出预算包括推理Token，并非实际用满值。兼容中转可能不支持max_tool_calls等参数；
本地固定候选数量、股票白名单、线程数和正式准入门槛始终生效，实际搜索次数以usage为准。
超时仍由OPENAI_TIMEOUT_SECONDS控制（30–300秒）；更充分研究可能增加延迟，部署者可按
实际超时记录调整。没有改写现有凭据或.env设置。

## 保持的边界

- Market First, News Second：先有实际强势信号，再验证共同催化。
- 2–3股本地观察零AI；先落库、展示和去重提醒，不等待其他候选的AI研究完成。
- 正式验证至少4只唯一强势股；AI不能新增本地输入外股票，不能为凑数扩池。
- 桥接2–4个具体节点、每节点至少2只、总共4–15只；文化传媒等宽泛父级仅作背景。
- 单轮最多8个桥接候选，最多3个并发，输出按本地评分顺序处理，稳定anchor保持不变。
- AI通过只形成formal_candidate，继续现有admission_analysis；新颖性、催化、持续性和证据门槛不降低。

## 扩大哪些可送审情形

4+2和重叠成员不再直接排除，重叠只按唯一代码计数。所有候选仍需bridge_score>=60。
常规路线保留同步/文本门槛；受限语义复核额外要求每节点至少两份实质业务理由，并使用以下依据之一：

1. 同步且有本地共同背景，业务文本明确涉及AI内容生产与IP/版权改编授权两个互补角色。
2. 文本相似度>=60，已观察启动跨度<=60分钟，允许研究是否为接力。
3. 文本相似度>=60且有本地共同背景，但启动时间未知；保持时间和同步指标为空，不伪造数据。

共享宽泛行业、同一时间上涨或价格资格模板都不足以创造共同事件；AI可merge/partial_merge/reject。
这些是需要查证的候选假设，不代表正式题材已经成立。

## 负面缓存复核

成功返回空结果或明确拒绝，不能在同一输入下永久阻止新催化验证。

- 同日交易时段、仍有>=4股本地有效候选、距上次运行至少30分钟时，允许再检查共同催化。
- 每个交易日+输入签名最多额外8轮；新股票/理由/图谱证据变化继续使用新签名正常验证。
- 部分成功时，仅向AI重送trace中被拒的节点/桥接；已通过集合继续使用原证据，不冒充新验证。
- 全成功缓存不按时重复研究；2–3股、没有合格本地候选、盘后和历史回放不触发定时复核。
- 接口失败仍走既有30分钟冷却；与成功负结论复核分别记录。
- discovery_review_history保存此前trace，discovery_negative_reviews记录轮次；
  service_runs的discovery_ai_recheck和当前trace记录本轮范围、结果和错误。不新增迁移。

缓存签名升级v3，包含桥接可能涉及的节点成员、理由、启动时间/依据和板态；不让孤立异动
无条件触发全市场AI。调用预算不能替代更好的数据源覆盖，AI也无法补回缺失的真实强势信号。

## 用量与效果评估

行情、资金流、评分、数据库和群机器人不消耗大模型Token。/health的ai_usage显示
last_24h/last_7d、by_task、input/output/reasoning/cached tokens及web_search_calls。
只有usage_complete=true才是完整统计；中转不返回usage时不能推算成真实账单。

应同时复盘：最早观察/提醒时间、有效候选覆盖、复核后恢复的候选、错误合并、正式准入结果、
AI延迟与实际调用量。当前回归证明这些候选可被送审且边界仍生效，没有使用真实AI回测，
不宣称已证明线上召回率提升或能保证零遗漏。不会为了降低调用数把有效新证据永久缓存掉。
