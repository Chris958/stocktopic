# 大方向题材池与再发酵

## 口径

正式池维护可持续跟踪的方向。机器人是题材名，特斯拉人形机器人产品进展是该方向下的一条催化；
新订单、技术更新和下一次产品进展不会每天各创建一个正式小题材。
机器人与低空经济等不同主线可以同时存在。四票是共振及AI验证触发门槛，不是题材名称的粒度。

本地明确同义标签先归到方向，例如机器人/人形机器人/具身智能归机器人。
其他方向也允许AI在固定本地节点和成员中概括共同产业方向；名称需由输入业务与已验证逻辑支持，
不能是单次发布/订单名或泛化的AI、科技、消费、文化传媒等空父类。
具体催化、原anchor和候选成员均保留。原`trade_date + anchor_tag`事件指纹不因方向名变化而改变。

## 两条准入路径

新方向继续走四股图谱/桥接验证，再检查新颖性、催化可信度、来源、持续性/情景空间和证据等级。

已有方向的延续或再激活，不能仅因已存在、`old_rotation`或用户手动归档而被拒绝。
依然需要至少四只当日强势股、AI逐股关系验证，并通过催化可信度、来源、持续性/空间与证据准入。
保留模型原始`novelty_mode`、`is_new_theme`和置信度，不把5分伪装为90分，也不伪造“全新催化”。
`admission_trace`明确记录`direction_continuation`或`direction_reactivation`及
`novelty_required=false`，与新方向分开解释。

已经正式准入且仍在池中的方向，新的已验证催化附在原记录下，不重复每日准入和发“新题材”通知。
历史同方向的多个正式事件按方向收敛，合并来源记录、审核和成员仍可追溯。
原ID、最早发现日期和首次正式入池时间保留；归档后的重新入池不会把老行情改成Day 1。

## 归档语义

归档表示暂时从当前池收起，后台仍跟踪。后续满足条件可自动重新进入正式池，也保留手动恢复。
原本只有2–3股的本地观察被归档后，也可在四股验证及证据准入通过后获得首次正式资格。

归档时保存成员/封板快照。相同的旧行情不会立即撤销归档；以下更新可触发再审：

- 后一交易日重新形成至少四只强势股；
- 当日出现新增强势成员或新增封板，并仍有至少四只共振。

历史回补不视作新的盘中再发酵。AI执行期间用户再次归档时，以较新的归档为准。
关系或证据验证失败继续留在观察/归档状态。准入被拒后，若成员或催化证据发生实质变化，
允许重开同一事件候选审查，保留旧拒绝历史；不因旧拒绝状态永久卡住。

## 每日成员更新

每次有效五分钟行情采集后，检查当日主板涨停/炸板、创业板最高涨幅超10%的本地强势事件。
本地图谱明确归属于已有方向的股票，可立即加入该方向成员，不需再凑四只新股票或再次调用AI。
归档方向的成员与强势数也会更新，但2–3股本身不触发正式恢复、AI或通知。

机器人新增成员要求机器人相关图谱边或既有正式成员依据，并检查当日理由冲突。
只有“轴承”“特斯拉”或汽车零部件标签不能直接推出机器人关系。
其他方向经固定候选验证过的具体节点关联，可保存成本地关系供后续更新；宽父类和多用途
零部件标签不能借此把无关股票塞入方向。
没有足够本地关系的股票等待验证，不从全市场自由寻找、扩展或为凑数生成代码。

首次可得时间、当日日期、原涨停原因、来源和关系依据写入成员证据。
反复采集不重复插入成员；同一事件候选重新审查时，当前触发成员以本轮验证集合为准，
不会把上次未被接受的成员拼回来充数。正式方向的已验证历史成员继续保留。

## 存储、通知与运维

不新增表、字段或migration，复用题材、成员、催化、审核、metadata与service_runs：

- `direction_state:<id>`：方向名、已验证节点关系、最近强势状态和最近30条事件记录；
- `direction_event:<candidate_id>`：事件名、原anchor、方向目标、归档代次和证据版本；
- `direction_archive:<id>`：手动归档时的行情快照；
- `direction_tracking:<date>:<id>`：当日强势股数、成员变化及是否符合再审条件；
- `direction_reject:<date>:<anchor>`：方向无法确定或尚无归档后新共振等原因；
- `direction_consolidation:<id>`：同方向历史正式事件的归属关系。

`discovery_audit`只读导出上述方向信息和准入路径。页面分别展示方向名称与当前催化，
归档按钮明确提示继续跟踪。首次正式及重新入池走飞书通知；重新入池使用归档代次去重，
重复采集、普通成员更新、2–3股本地观察不新增机器人通知。

回归使用合成数据和假AI，覆盖机器人与低空并存、非机器人方向归纳、跨日/同日再发酵、
归档观察首次正式准入、AI拒绝与证据不足、拒绝后新证据重审、用户归档竞争、日内成员立即补入、
旧行情不撤销归档、历史回补不激活、原ID与Day 1保留。源/图谱标签缺失仍可能延迟关系确认，
这些回归不代替逐时点历史收益回测。
