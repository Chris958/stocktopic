# Level-2主动委托资金说明

## 数据与安全

系统使用猫爪数据的以下单股单日接口：

- `level2_trade_history`：逐笔成交，读取`amount`、`bs_flag`、`buy_order_id`、`sell_order_id`；
- `level2_order_history`：逐笔委托，读取`side`、`order_type`和`order_no`，首版用于字段口径审计。

请求固定发送到`https://numcat.net/api`，API Key只从本机`NUMCAT_API_KEY`读取。系统不会把Key写入数据库、报告、页面或日志。

未指定日期时，盘中会从最近一个已完成交易日开始查询；16:00后会先尝试当天。若猫爪返回`1002`或空数据，系统会依次回退到最近5个已完成交易日。指定`--date`时严格查询该日，不自动改用其他日期。若均无数据，错误信息会列出所有尝试日期，便于核对套餐权限和历史覆盖范围。

## 计算口径

对每一笔有效成交：

1. 根据`bs_flag`确认主动方向；
2. 主动买入取`buy_order_id`，主动卖出取`sell_order_id`；
3. 按`方向 + 委托号`分组，累计成交金额、成交量、成交笔数、首末时间和成交价格数；
4. 聚合金额达到50万元或100万元后，分别进入对应统计。

设门槛为`T`，达到门槛的主动买入委托集合为`B_T`，主动卖出委托集合为`S_T`：

\[
买入占比_T=\frac{\sum B_T}{\sum B_T+\sum S_T}\times100\%
\]

\[
净主动流入_T=\sum B_T-\sum S_T
\]

100万元以上委托同时属于50万元以上集合；两档是独立观察口径，不应相加。

## 事件标签

- 同一主动买委托在2秒内出现至少2笔成交：连续扫单；
- 同一主动卖委托在2秒内出现至少2笔成交：连续砸盘；
- 主动买委托全部在当日涨停价成交：涨停板扫单；
- 其他达到50万元的委托：主动买单或主动卖单。

“连续扫单”表示同一主动委托连续产生成交，不等于已证明穿越多个盘口档位。页面同时展示成交笔数、时间和委托号，便于人工复核。

## 暂不自动下结论的信号

以下信号必须先用海鸥股份及更多沪深样本确认猫爪返回的原始代码：

- 大单撤单：需要校准`order_type`的新增、撤单及取消映射，并关联原始委托；
- 封板资金：需要结合涨停价十档盘口或封单快照，而不是把涨停成交额当封单；
- 炸板卖单：需要同时确认开板时点与主动卖出委托；
- 反复点火、吸筹：需要多个时间窗口和价格路径验证，不能由单日净流入直接推断。

## 可信度检查

每份报告必须显示：

- 主动方向金额覆盖率；
- 主动方委托号金额覆盖率；
- `bs_flag`、`trade_code`、`side`和`order_type`原始值分布；
- 是否为盘中未完成数据。

若主动方向或委托号覆盖率明显偏低，50W+/100W+结果只能作为不完整样本，不能进入题材强弱与龙头评分。
