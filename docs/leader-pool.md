# 龙头候选池

首页「发现」顶部先显示低位候选与当前机会，再显示高标参考。默认展示 6 只，可展开查看全部，
每个方向最多 2 只，同时跟踪最多 12 只不同股票。股票代码作为身份：同一只股票归属多个方向只列一次。
每只保留首次入池的实盘时间、当时的涨停观测日期和共振依据；每天不重新挑赢家，也不会因一次没涨停被移出。

## 决策规则

| 阶段 | 首版口径 |
| --- | --- |
| 入池 | 至少两个沪深主板成员在同方向走强（实际涨停或当前涨幅至少 3%）。候选本身须在近五个交易日内至少有一次可核验的实际涨停。优先已正式准入的方向；具体本地节点也可进入观察，宽父类本身不构成来源。候选优先参考当天封板先后、随后触板的同方向成员与相对强度。 |
| 等 | 高标（已有至少 3 连板证据）只作情绪参考。未正式准入或处于归档期的方向、涨停价买入条件不明确、没有跟随或没有足够隔日证据，均继续等待。非交易时段或行情失效后不展示有效机会。 |
| 关注机会 | 仅正式方向的低位候选。用入池时固定的对照股看回踩（先有强度、回撤至少 1 个百分点），候选先修复且在后续样本维持，同方向至少一只股票随后从回踩水平明显走强。初始阈值为修复至少 0.7 个百分点，跟随股较回踩至少改善 0.8 个百分点，需有前后四次有效采样。分歧中看候选相对抗跌；平稳发酵中也允许观察回踩后续强。 |
| 窗口失效 | 信号时刻、跟随股票、已观察到的回踩低价写在当前卡片上。跌回回踩低位、跟随回落、出现明显负反馈、或最长 20 分钟到期，均回到「等」。午休、收盘、断采样后重新确认。 |
| 移出 | 同一方向连续两个有足够样本的交易日收盘，出现题材与个股同步走弱，或有其他成分股持续走强而原候选掉队，才结束该方向的跟踪。缺行情不算退潮。题材归档已超过首次发现后 14 个自然日或不再属于有效主板范围时，也结束相关跟踪。若仍有另一有效方向，股票继续留池；最后一个方向结束才记录整只股票移出。 |

初版门槛是可回放的规则参数，尚不是经实盘验证的胜率、买入指令或收益预测。五分钟采样只能
识别观察到的相对抗跌和跟随，不识别交易人身份或精确封板次数。连续弱势以正式日线收盘价为准，下一批盘中更新时复核；缺失收盘样本不会累加退潮天数。正式题材仍要求至少四只当日实际涨停通过原准入，
2–3 股早期观察不调用 AI、不通知；本池的机会窗口先在网页展示，现有飞书机会通知规则保留。

## 数据与接口

- 负反馈同时兼容 `YYYYMMDD` 和 `YYYY-MM-DD`，不把前一天收盘或采样不全当成当日收益。
  昨日涨停股的涨跌中位数、大幅走弱比例按实际可观测样本计算，页面显示有效数与应有数；
  有效覆盖不足 80% 标记待验证。连板解析共用同一规则，不把「4天3板」读成「43板」。
- 隔日收益取下一交易日正式日线收盘，有效 15:00 样本可先结算，日线到达后校正。
  除权后的昨收作为收益分母，不把未结算或缺失计为 0；启动后在后台用本地数据补算最近
  20 个已结束交易日。无法核对的旧记录保持原始状态；没有另外拉全市场数据。
- `GET /api/v1/leader-pool` 返回已保存的候选快照与当前窗口是否仍有效。
  `GET /api/v1/leader-pool/history` 支持 `limit` 和 `before` 分页，返回每次入池和移出的时间、方向、原因。
  两个接口沿用现有登录认证，页面只读，不在访问时查询全市场行情、不重跑筛选。
- 快照、采样状态和出入池历史沿用现有 SQLite `metadata`，一次事务写入，没有数据库迁移。
  观察从部署后的第一批有效盘中报价开始，不用事后数据倒填过去曾经有的机会。
