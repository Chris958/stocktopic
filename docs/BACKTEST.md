# 测试票池与回测口径

测试票池用于验证“在题材股票列表发出人工跟踪信号后，下一交易日开盘买入是否具有隔日优势”。它是前向纸面记录，不会下单，也不会修改题材准入或接盘风险评分。

## 时间定义

- T：点击跟踪时对应的最近交易日，即信号交易日；
- T+1：T之后的首个交易日，盘中以 `rt_k` 开盘价确认买入，收盘后由正式日线校准；
- T+2：T之后的第二个交易日，正常情况下以开盘价作为标准卖出价，以最高价计算最高可能收益；
- 非交易日点击时，T取最近一个已经存在的交易日；同一股票同一T只生成一笔记录。

## 成交处理

- T+1一字涨停、停牌、日线缺失或开盘价无效：标记“未成交”，不计入成功率和收益；
- 普通开盘股票在09:30后的首个有效五分钟行情更新为“持有中”，同时保存现价、持仓涨跌、
  当日最高价和最高涨幅；
- 开盘即封涨停且仍为单一价格时显示“涨停待确认”，盘中打开后才暂记成交，收盘正式日线
  仍可将全天一字涨停反向校正为“未成交”；
- T+2一字跌停、停牌、日线缺失或开盘价无效：不能假设开盘卖出，逐交易日顺延；
- 顺延后的首个可卖交易日以其开盘价结算标准收益，以其最高价结算最高可能收益，并保存实际退出日及延迟交易日数；
- 一字板判断适用于系统覆盖的非ST沪深主板股票：OHLC完全一致且涨跌幅达到约10%的涨跌停区间。

## 统计公式

单笔标准收益：

```text
(实际退出开盘价 / T+1买入开盘价 - 1) × 100%
```

单笔最高可能收益：

```text
(实际退出日最高价 / T+1买入开盘价 - 1) × 100%
```

开盘卖出价高于买入价为成功，低于为失败，完全相等为持平。成功率为：

```text
成功笔数 / (成功笔数 + 失败笔数)
```

持平记录收益为0，但不进入成功率分母。汇总标准收益与最高可能收益都是已完成有效记录的等权算术平均，即每笔假设投入相同金额。未成交记录不进入收益统计。

## 数据与调度

- 盘中确认与持仓标记使用系统已有的Tushare `rt_k` 五分钟行情，不增加全市场调用；
- 最终买入价、成交有效性及退出结算使用Tushare `daily`正式日线；
- 服务启动、08:35和17:10检查待结算日期；
- 每个交易日只在全量日线覆盖达到2000只后标记同步成功；
- 停机、升级或网络故障不会把缺失日线当成0，恢复后自动回补；
- 日线拉取失败写入服务任务、网页预警并尝试企业微信告警。

“最高可能收益”使用事后当日最高价，仅用于衡量股票在退出日提供过的理论空间，存在明显的前视属性，不能当作可复制交易收益。标准收益才是固定规则的主要评估口径。
