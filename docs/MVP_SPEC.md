# V2题材阶段识别规格

## 产品边界

- 用户：仅项目所有者本人。
- 市场：沪深主板；排除科创板、创业板、北交所、ST及退市整理股票。
- 系统关系：独立系统，不依赖现有产业链系统的数据库或代码。
- 数据主源：Tushare `rt_k`；FutuOpenD以后作为龙头细节与交叉验证增强源。
- 更新频率：全市场5分钟，聚类15分钟，硬事件即时触发。
- 历史：先做日线验证，从上线日积累5分钟历史。

## 高信号异动池

硬事件包括封板、炸板、放量快速拉升、跌停和快速大幅负反馈，可直接进入。普通正向股票必须同时获得“价格确认”和“流动性确认”，不再允许两个同类价格指标直接触发：

- 价格确认：当日涨幅至少6.5%，或5分钟涨幅至少2.5%；
- 流动性确认：5分钟增量成交额至少5000万元且达到前周期2.5倍，或成交笔数增量至少600笔且达到前周期2.5倍；
- 5分钟涨幅至少4%且增量成交额至少8000万元属于硬事件；
- 异动页每只股票只保留最近一次高信号事件，默认显示强度不低于68或硬事件。

股票涨跌停价以Tushare `stk_limit`为准，不对新股、特殊价格限制进行主观估算。涨跌停价缺失时，仍可识别普通涨跌幅与量价异动，但不生成封板或炸板标签。

## 候选题材

- 股票成员仅由异动规则与标签交集确定。
- 行业标签至少4只共同异动；概念/题材标签至少3只。
- 候选需至少含一个硬事件，或成员平均异动强度不低于75。
- 高重合候选按成员交集去重，行业宽标签让位于更具体的题材标签。
- 单次聚类最多新增8个高信号候选，可通过环境变量调整。
- 候选立即显示股票、异动原因和标签证据。
- 人工可确认、忽略、合并、拆分。
- 确认前 `theme_scores` 不写入记录，API返回 `score: null`。
- Day 1是机器首次发现共性异动的交易日，确认后保留并回溯到该日。

## AI边界

OpenAI输入中的股票列表被标注为只读，输出结构不含股票成员字段。它只完成：

1. 最小共同炒作逻辑命名；
2. 与现有题材的合并建议；
3. 最近72小时新闻、政策、公告催化解释；
4. 催化可能持续时间的文字说明。

模型不可确认题材、不可更改成员、不可决定评分、不可输出自动交易指令。

已确认和高优先级候选在交易日08:40、10:30、13:30、15:30定时更新催化。催化按URL、标题和日期去重，保存首次催化、强化催化、降温/证伪、来源、发布时间及“明确证据/合理推断”标签。海外隔夜事件在盘前轮次纳入搜索。

## 个股阶段与龙头

- 当前涨幅来自最近一次 `rt_k` 快照；收市后保留最后快照。
- 题材确认后累计涨幅，以确认时最近可用价格为基准；候选阶段显示发现后累计涨幅。
- 流通市值来自 `daily_basic.circ_mv`，盘后更新，页面标注数据日期。
- 近期连板、首次涨停、最后封板、开板和封单来自 `kpl_list`，首次升级回补最近5个交易日。
- 股票列表始终按当前涨幅纵向降序，历史成员关系保留，当前异动成员单独标记。
- 龙头候选综合连板高度、涨幅、首次封板顺序、首次异动顺序，以及其后30分钟出现的跟随股数量；该结果是结构识别，不是买卖建议。

## 推送

- 系统内：所有候选、评分和风险实时显示。
- 企业微信：高持续性低风险机会、接盘风险、龙头—板块背离、数据陈旧和采集故障。
- 同题材同类预警每小时最多一条，企业微信接口同时启用重复检查。
- 数据陈旧时禁止发出新的机会推送；故障和风险推送不受此限制。
