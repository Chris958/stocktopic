# V3新重点题材准入规格

## 产品目标

系统只识别“刚开始形成资金共识、具备持续性的新重点题材”，不向用户罗列普通个股异动、小题材或反复轮动的旧题材。

- 市场：沪深主板；排除科创板、创业板、北交所、ST及退市整理股票。
- 行情：Tushare `rt_k` 每5分钟；开盘啦涨停与概念接口提供题材、涨停原因和股票池。
- 展示：网页不提供个股异动池。底层异动仅保留给龙头带动、风险评分和审计。
- 历史：以最近60个交易日判断同逻辑是否已经发酵或反复炒作。

## 第一层：数据质量门禁

- `pre_close<=0` 或 `close<=0` 的行情不可用于涨跌幅、异动或题材判断。
- 集合竞价暂无有效价格时跳过该股票；绝不把 `close=0` 计算为 `-100%`。
- 连续交易阶段有效主板行情不足2000只时熔断本周期，并生成企业微信数据故障告警。
- 全市场累计成交额和成交量未变化时判定数据陈旧，禁止生成机会信号。
- 升级数据库时清理历史 `close<=0` 快照及 `pct_change<=-99` 异动记录。

## 第二层：确定性涨停门槛

- 只使用开盘啦题材标签聚类当日涨停与炸板股票。
- 同题材当日累计至少4只股票曾触及涨停，才允许创建准入候选。
- 当前炸板股票计入4只门槛，但封板数、炸板数、首次封板时间分别保存。
- 同一股票同一题材只计一次；高度重合的近义标签只保留最强代表。
- 单轮最多产生4个候选，未达门槛的主题只保留底层数据，不展示、不调用AI。

## 第三层：60交易日新颖性审查

系统向AI提供候选题材、触板股票、历史相似题材及股票重合度。AI必须搜索公开信息并判断：

1. 是否为新的最小共同炒作逻辑；
2. 是否只是旧题材换名、新新闻刺激或反复轮动；
3. 当前催化与过去60个交易日的核心区别；
4. 存在哪些反证和证伪条件。

自动准入要求 `is_new_theme=true` 且新颖性置信度不低于70。

## 第四层：催化与持续性审查

- 催化可信度不低于65；
- 至少保存一条由Web搜索实际返回、带原始URL、标记为“明确证据”的催化；
- 预估持续至少3个交易日，或龙头候选的有条件情景空间至少30%；
- 龙头代码必须来自触板股票或确定性股票白名单；
- 30%是情景空间，不是目标价，必须同时保存成立条件和反证。

任一关键门槛失败，候选转为不准入状态，不进入重点题材库，也不推送新题材提醒。

## 第五层：股票池扩展

- 系统先从开盘啦题材成分生成高置信白名单；
- AI只能从白名单中提出同逻辑股票、角色和依据；
- 系统再次校验股票代码、题材标签来源和置信度；
- 通过校验后自动加入题材股票池；AI自行创造或白名单外的代码全部丢弃；
- 触板股票始终保留原始封板与炸板证据。

## 自动入库与推送

通过全部准入门槛后：

1. 自动确认题材并保留首次发现日为Day 1；
2. 保存准入审查、新颖性、催化、持续天数、龙头空间、反证与扩展股票；
3. 生成Heat、Persistence、Entry Risk；
4. 发送“新重点题材”企业微信，包含触发、核心股票、催化、持续天数、龙头候选和情景空间；
5. 后续在08:40、10:30、13:30、15:30更新新闻催化列表。

## 题材库交互

- 已确认题材可置顶，置顶题材优先排序；
- “移除”采用可恢复归档，不永久删除历史；
- 股票行情榜与新闻催化分别折叠，展开状态保存在当前设备；
- 股票始终按当前涨幅纵向降序，显示当前涨幅、入库后累计涨幅、连板、流通市值、封板顺序和带动数；
- 已归档题材可在筛选器中恢复。

## 故障告警

交易日历、股票池、涨跌停价、日度指标、开盘啦数据、实时行情、AI准入和新闻更新失败均写入预警表并尝试企业微信推送。企业微信自身失败时记录阶段、`errcode`、建议及最近成功时间；微信不可用期间无法通过同一微信通道报告其自身故障，因此网页和日志是必要的备用可见入口。
